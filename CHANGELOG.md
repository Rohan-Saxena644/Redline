# Changelog

## 0.1.0 — 2026-11-05

Initial experimental release: portable TypeScript policy SDK with ESM/CJS/declarations; original 24-product USD shop; bounded OpenAI-compatible structured action agent and explicit fixtures; sandbox-only PayPal adapter and durable payment simulator; exact approvals, PostgreSQL reservations/locking, state recovery and signature-verified webhook routing; six adversarial scenarios; redacted receipts and deterministic replay; responsive purchasing workspace; offline packed consumer; local setup, operations and submission documents.

Live model and PayPal sandbox checkout are implemented but unverified without configured approved credentials. Experimental APIs may change before 1.0. No package has been published.
